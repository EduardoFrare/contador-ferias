# 🏖️ Operação Sobrevivência: Volta do Duduzinho 💼

Um site hilário e motivacional feito sob medida para o time acompanhar cada dia, hora, minuto e segundo até o retorno do **Duduzinho** das suas férias!

---

## 🌟 Funcionalidades Incríveis

- **⏱️ Cronômetro em Tempo Real**: Conta regressiva com precisão de 17 dias (até **02 de Setembro às 14:00**).
- **☕ Sobrevivômetro do Time**: Tickers dinâmicos de xícaras de café consumidas, reuniões desnecessárias evadidas e nível da bateria emocional da equipe.
- **🚨 MODO PÂNICO (ALGUÉM OLHANDO)**: Botão de pânico que abre instantaneamente uma **planilha do Microsoft Excel ultra-realista** (para fingir trabalho urgente caso alguém se aproxime da sua tela!). Pressione `ESC` para voltar ao cronômetro.
- **💡 Gerador de Conselhos de Sobrevivência**: Dicas corporativas divertidas para contornar qualquer pergunta difícil enquanto o Duduzinho está fora.
- **📌 Mural de Recados Sticky Notes**: Permite que o time deixe recados engraçados salvos localmente.
- **⚙️ Configuração Personalizável**: Ajuste a data/hora de retorno a qualquer momento caso haja mudanças na viagem.
- **🎉 Celebração com Confetes**: Dispara confetes festivos assim que o contador zera!

---

## 🚀 Como Executar Localmente

1. Abra o terminal na pasta do projeto:
   ```bash
   cd contador-ferias
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra o link gerado (ex: `http://localhost:5173`) no seu navegador!

## ☁️ Como Hospedar Gratuitamente na Vercel

### Opção 1: Via Vercel Web (Recomendado & Fácil)
1. Suba esta pasta para um repositório no seu **GitHub**.
2. Acesse [vercel.com](https://vercel.com) e faça login.
3. Clique em **"Add New..."** ➔ **"Project"**.
4. Selecione o seu repositório no GitHub.
5. A Vercel detectará automaticamente o framework **Vite**.
6. Clique em **"Deploy"**! Em menos de 1 minuto seu site estará no ar com link público para mandar no grupo do trabalho! 🚀

### Opção 2: Via Linha de Comando (Vercel CLI)
No terminal na pasta do projeto, rode:
```bash
npx vercel
```
Siga as instruções na tela e o projeto será publicado em instantes!
